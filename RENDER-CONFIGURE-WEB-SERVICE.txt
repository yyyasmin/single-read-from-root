================================================================================
RENDER - CONFIGURE YOUR WEB SERVICE (step 2)
================================================================================

You have:  yyyasmin / single-read-from-root  (good)

Now fill in the form on the same page:

  Name
  ->  reading-from-root-api   (or any name you like)

  Region
  ->  Leave default (e.g. Oregon or closest to you)

  Branch
  ->  main   (or  master  if your repo uses master)

  Root Directory
  ->  backend
  (Important: so Render uses only the backend folder.)

  Runtime
  ->  Python 3

  Build Command
  ->  pip install -r requirements.txt

  Start Command
  ->  gunicorn app:app --bind 0.0.0.0:$PORT

  Instance Type
  ->  Free   (if you see it)

Then click "Create Web Service" (or "Deploy") at the bottom.

Wait for the first deploy to finish. Copy the URL Render gives you (e.g. https://reading-from-root-api.onrender.com) and add it in Netlify as VITE_API_URL.
