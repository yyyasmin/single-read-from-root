איך להריץ את האתר LOCALLY (מהמחשב) – בלי להיתקע על "טוען..."
================================================================================

הפרונט (Vite) מחפש את הנתונים בכתובת http://localhost:5000 (באמצעות proxy).
אם רק מריצים "npm start" – אין שרת על 5000, ולכן האתר נשאר על "טוען...".

פתרון: להריץ גם את הבקאנד (Flask) בטרמינל נפרד.

--------------------------------------------------------------------------------
שלב 1 – טרמינל ראשון (בקאנד)
--------------------------------------------------------------------------------
פתח טרמינל (PowerShell או CMD), עבור לתיקיית הפרויקט והרץ:

  cd "C:\Users\Yair Amran\Documents\שיבולים\לקרוא מן השורש"
  cd backend
  python app.py

(אם יש לך venv: backend\venv\Scripts\activate ואז python app.py)

אמור להופיע משהו כמו: Running on http://127.0.0.1:5000
השאר את הטרמינל הזה פתוח.

--------------------------------------------------------------------------------
שלב 2 – טרמינל שני (פרונט)
--------------------------------------------------------------------------------
פתח טרמינל שני:

  cd "C:\Users\Yair Amran\Documents\שיבולים\לקרוא מן השורש\frontend"
  npm start

אחרי ששניהם רצים – רענן את הדף בדפדפן (http://localhost:3000).
האתר אמור להיטען בלי להיתקע על "טוען...".

--------------------------------------------------------------------------------
אלטרנטיבה – הרצה ביחד
--------------------------------------------------------------------------------
מהשורש של הפרויקט אפשר להריץ:

  python run.py

זה מפעיל גם את הבקאנד וגם את הפרונט together (אין צורך בשני טרמינלים).
